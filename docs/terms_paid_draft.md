# 유료 상품 약관 초안 (결제 오픈 직전에 terms.html 4번 항목과 교체)

※ 법률 검토를 받은 문서가 아니에요. 공개 전에 통신판매업 신고, 전문가 확인을 거치세요.

## 4. 유료 상품 (결제 시작 후 적용)
1. 판매하는 상품은 ① 유료 스킨(영구) ② 닉네임 변경권 ③ 서버 후원이에요. 가격·사용 기간은 결제 화면에 먼저 보여 드려요.
2. 유료 스킨과 닉네임 변경권은 게임 안에서만 쓰는 디지털 상품이에요. 현금으로 바꾸거나 다른 사람에게 팔 수 없어요.
3. **청약 철회·환불**: 결제 후 7일 이내이고 상품을 아직 쓰지 않았다면 전액 환불해 드려요. 이미 적용·사용한 디지털 상품은 법령이 허용하는 범위에서 환불이 제한될 수 있고, 이 사실을 결제 전에 알려 드려요. 상품에 문제가 있으면 기간과 상관없이 환불·교환해 드려요.
4. **서버 후원**은 서버 유지비에 쓰이는 자발적 후원이에요. 보상이 없고, 후원금은 환불이 되지 않아요 (결제 오류는 제외).
5. **미성년자**: 만 19세 미만은 법정대리인의 동의 없이 결제하면 본인 또는 법정대리인이 결제를 취소할 수 있어요.
6. **확률형 아이템**: 무료 룰렛은 돈이 들지 않으며, 당첨 확률은 이벤트 화면에 항상 표시해요. 유료로 파는 확률형 상품은 지금 없어요. 앞으로 만들면 확률을 구매 전에 공개해요.
7. 환불·문의: 게임 안 문의 또는 아래 사업자 연락처 (상호: ____ / 대표: ____ / 사업자등록번호: ____ / 통신판매업 신고번호: ____ / 연락처: ____).
8. 서비스를 끝낼 때는 최소 30일 전에 알리고, 남은 유료 상품은 환불해요.

## 결제 오픈 전 체크리스트
- [ ] 통신판매업 신고 (구청, 온라인) 및 사업자 정보 위 칸 채우기
- [ ] GCRB 등급분류 완료 (등급 표시를 게임 화면에 넣기)
- [ ] 포트원 가맹점 심사, 테스트 결제 확인
- [ ] 결제 화면에 환불 규정, 후원은 환불 불가 문구 표시
- [ ] 개인정보 처리방침에 결제 정보(포트원) 항목 추가
